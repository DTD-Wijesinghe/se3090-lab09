# Student Task Manager

SE3090 Software Engineering Frameworks - Lab Practical 09.

## Run

1. Install Flutter and start an Android emulator or connect an Android device.
2. From this folder run `flutter create .` once to generate the platform runner files.
3. Run `flutter pub get` and then `flutter run`.

The app uses one Dart source file in `lib/main.dart` and implements the required task input, validation, state updates, scrolling list, deletion, SnackBar feedback, and live task counter.
